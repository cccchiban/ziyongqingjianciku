# 自用青简词库

青简输入法自用词库，`其他/` 收番剧名称、国际新闻、网络热梗、国内舆论事件、国产游戏、互联网软件、AI 词汇与互联网黑话等主题词库，另设 `私域/` 收单社区黑话、`网文小说/` 收单部网文专名、`文学作品/` 收古典诗文与文学专名、`计算机词库/` 收计算机与互联网术语、`电力电气/` 收电力与电气工程技术词、`通信与无线电/` 收通信与无线电术语、`电子工程/` 收电子与半导体术语、`电商/` 收跨境电商平台专名词库、`英语/` 收英语语种词库、`动漫/` 收动漫与 ACG 专名词库、`常用词/` 收评论语料统计的高频口语词、`游戏/` 收单游戏专名词库，另设 `动物/` 收中文名、学名与俗名三列的动物名录（其正名与俗名另派生为输入法词条并已并入综合库），另设 `植物/` 收中文名、学名与俗名三列的植物名录（其派生词库已并入综合库）。

## 文件格式

每行一条词条，三个字段以 Tab 分隔。

```
青简	qing jian	100
```

- 第一列 词面：词内不含空格。
- 第二列 拼音：逐音节以空格分隔，可带数字声调（`ni3 hao3`），轻声写 5 或 0。
- 第三列 词频：正整数，按常用度分档。

拼音中 ü 写作 `v`，写成 `lue` / `nue` 的同样识别。文件为 UTF-8 编码、`\n` 行尾，末行保留换行。
