## 文件格式

每行一条词条，三个字段以 Tab 分隔。

```
青简	qing jian	100
```

- 第一列 词面：词内不含空格。
- 第二列 拼音：逐音节以空格分隔，可带数字声调（`ni3 hao3`），轻声写 5 或 0。
- 第三列 词频：正整数，按常用度分档。

拼音中 ü 写作 `v`，写成 `lue` / `nue` 的同样识别。文件为 UTF-8 编码、`\n` 行尾，末行保留换行。

## 综合词库

`综合词库.qj` 由源词库按词面去重合并：词频取各源最大值，拼音取源库值，排序为词频降序、同频按拼音升序、再按词面。当前版本合并日番、国际新闻、国番、网络热梗、国内舆论事件、国内游戏名称、互联网软件名称、AI 常用词汇、互联网黑话九个源库，外加 `游戏/游戏词库合集.qj` 的 31273 条、`私域/` 四个词库的 621 条与 `网文小说/` 五部的 785 条；游戏合集与既有源库重叠 42 条，均为游戏本名；私域库与其它源库重叠 81 条，网文小说库生成时共剔除 53 个与既有库重复的候选词，判重为大小写不敏感，重复词已从这些库剔除，各子库之间互不重复。
